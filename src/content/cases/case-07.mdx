Change events from HubSpot and Salesforce land in one ordered n8n queue,
translate through a single field map, and pass explicit conflict rules
before writing back. Upserts use external IDs so replays never duplicate a
record, and failures land in a dead-letter queue instead of silently
dropping. The full mapping table and retry logic ship with the Phase 3
build.
