PostHog usage events and Stripe billing signals converge in an n8n scorer
that writes a weighted health score per account to Postgres. A drop past
threshold alerts the owner in Slack while there is still time to act.

Not built yet. The scoring model and the thresholds go up with the first
alert the system fires for real.
