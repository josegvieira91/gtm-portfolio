Apollo saved searches feed an n8n pipeline where OpenAI drafts one email
per prospect from enriched fields. A deterministic QA gate loops weak
drafts back for a rewrite, and only approved copy reaches Instantly for
sending. The full personalization prompts and gate rules ship with the
Phase 3 build.
