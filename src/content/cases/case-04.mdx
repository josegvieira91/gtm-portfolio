A Make scenario sweeps HubSpot nightly for duplicates, dead fields, and
stale owners. Exact-match dupes merge themselves under deterministic rules,
ambiguous matches queue for a human, and every run ends with a Slack digest
of what changed. The full rule set and audit trail ship with the Phase 3
build.
